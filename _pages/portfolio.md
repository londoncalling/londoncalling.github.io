<section class="philosophy">
  <div class="wrap">
    <h2>My approach</h2>
    <h3>Documentation philosophy</h3>
    <p class="philosophy-intro">Great documentation isn't just about accuracy. It's about empathy, clarity, and reducing friction at every step. Every piece of content I create is designed to get developers productive faster.</p>
    
    <div class="philosophy-examples">
      <div class="philosophy-item">
        <h4>Explain the why, not just the what</h4>
        <div class="example">
          <div class="example-bad">
            <span class="example-label">✗ Don't</span>
            <p>Set <code>timeout</code> to <code>30</code>.</p>
          </div>
          <div class="example-good">
            <span class="example-label">✓ Do</span>
            <p>To reduce the risk that a long-running query blocks other operations, set <code>timeout</code> to <code>30</code>.</p>
          </div>
        </div>
      </div>
      
      <div class="philosophy-item">
        <h4>Front-load critical information</h4>
        <div class="example">
          <div class="example-bad">
            <span class="example-label">✗ Don't</span>
            <p>This release includes several improvements to performance and adds new features. Note that the authentication method has changed and is not backward compatible.</p>
          </div>
          <div class="example-good">
            <span class="example-label">✓ Do</span>
            <p>Version 3.0 breaks backward compatibility with the authentication method. Before you upgrade, migrate to OAuth 2.0.</p>
          </div>
        </div>
      </div>
      
      <div class="philosophy-item">
        <h4>Anticipate the next question</h4>
        <div class="example">
          <div class="example-bad">
            <span class="example-label">✗ Don't</span>
            <p>Enable caching to improve performance.</p>
          </div>
          <div class="example-good">
            <span class="example-label">✓ Do</span>
            <p>To improve performance, enable caching. If your data changes frequently, set <code>cache_ttl</code> to <code>60</code> seconds or less to prevent stale results.</p>
          </div>
        </div>
      </div>
      
      <div class="philosophy-item">
        <h4>Trust technical competence</h4>
        <div class="example">
          <div class="example-bad">
            <span class="example-label">✗ Don't</span>
            <p>A database is a system that stores data. Configure your database connection string, which is the text that tells your application where to find the database.</p>
          </div>
          <div class="example-good">
            <span class="example-label">✓ Do</span>
            <p>Configure your connection string to point to the primary replica. Use the secondary replica only for read operations.</p>
          </div>
        </div>
      </div>
    </div>
  </div>
</section>
